# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `designcraft-brochure`：产品宣传册（多页宣传册排版）
- `designcraft-catalog`：商品目录（大量商品信息的版式统一）
- `designcraft-newsletter`：多栏刊物（简报、通讯与多栏文字）
- `designcraft-poster-layout`：活动海报排版（海报信息层级和大幅输出）
- `designcraft-long-document`：长文档排版（章节、目录、页码与统一样式）
- `designcraft-print-preflight`：印前排版检查（字体、图像、出血与导出检查）
