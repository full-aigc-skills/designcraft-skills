# DesignCraft CLI 0.2.1 原生格式导出观察

此目录保存隔离样本工程的原生导出回执、计划、实际产物、离线结构探针和浏览器渲染预览。摘要明确记录每种格式的观察状态、字节/SHA、限制与未验证项。

本次同批导出在 `file.exportText` 步骤前以非零退出结束；前六个结果仍被保存。XML 输出只有空 `Root`，不能作为内容导出通过。原始观察时 IDML 和 EPUB 尚未在目标应用/阅读器中重开，PNG/JPEG/WebP/TIFF 不在固定命令目录中。此证据是部分格式观察，不满足完整 2.6b 验收。
