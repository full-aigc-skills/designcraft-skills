## Why

现有六项技能已具备固定运行时、命令发现和单会话计划入口，但领域流程高度重复；组合调用会丢失内层超时的 UNKNOWN 语义，零退出也不能证明工程和导出满足要求。需要将 Dreamina 的路由、契约、恢复和证据分层适配到本地排版工作流，为插件消费提供可靠的唯一事实源。

## What Changes

- 保留六项独立技能，明确 use 路由、CLI 公共契约、setup、document、layout、export 的边界，补充渐进式参考资料与完整场景。
- 加固启动器和网关的结构化结果传递，区分短任务、长驻 MCP、超时未知、部分执行和中断；禁止未知写入自动重放。
- 增加 runId、检查点、运行时与输入身份、步骤结果和恢复建议；保留公开 argv 入口及单技能自包含能力。
- 增加原生业务结果解析、输出清单、保存重开、逐页预览和可追溯审阅，区分结构、视觉、格式及可编辑性验收。
- 建立命令归属、版本绑定、场景测试、独立检出验证和固定原生制品验收。原生与宿主证据不由模拟测试替代。
- 补齐 Dreamina 对照后识别出的技能文档质量门禁：统一入口内容、渐进式资料引用，以及成功/拒绝/恢复案例的覆盖追溯。
- 对新增版本化回执保留旧回执只读识别；旧记录缺少检查点或身份时不得自动恢复。保留现有六个技能名、计划 command/params 及脚本入口。

## Capabilities

### New Capabilities
- `skill-routing-contracts`: 六项技能职责、资料、命令归属与独立运行。
- `native-execution-lifecycle`: 进程结果、任务身份、检查点、输入保全及未知状态恢复。
- `artifact-verification`: 原生业务结果、产物、重开、逐页审阅与修订证据。
- `skill-quality-gates`: 分层测试、固定原生验收、证据时效和技能维护门禁。

### Modified Capabilities
无既有 OpenSpec 主规范；以上为首次记录的目标契约，包含既有行为保护及新增要求，不表示能力已实现。

## Impact

- 影响 skills/* 的 SKILL.md、references、examples、agents 元数据与 scripts，以及包级校验、测试、验证资料。
- 本项目拥有共享运行时、执行、回执和产物契约；消费者为 designcraft-plugin 的 `harden-designcraft-plugin-delivery`，该插件不得复制定义一套新契约。
- 默认首个真实平台为现有锁支持的 macOS arm64、Python 3.11+、原生 CLI 0.2.1；新版本必须显式更新锁与验证。
- 仅借鉴 Dreamina 的技能分工、渐进式资料、显式交接、状态恢复和证据分层；不移植其账号、积分、云端任务或媒体生成契约。
- 本次仅落规格和任务。安装/升级、首次宿主集成、Git 初始化、提交推送、发行及市场更新按后续实际授权执行；不因本提案自动获准。
- 不移植 Dreamina 付费、登录和 token 流程；不默认扩大平台、自动多轮、并发任务或 ArtCraft 集成范围。
