## Purpose

明确六项独立技能如何选择任务入口、维护公共契约与领域流程，使独立安装和插件调用具有一致的行为，并以实际固定原生能力作为执行依据，避免路由重叠及文档重复造成错误操作。

## ADDED Requirements

### Requirement: SK-01 六项技能职责与路由

技能库 SHALL 保留现有六个技能名，以 designcraft-use 路由未指定操作的排版任务；CLI 维护公共契约，setup/document/layout/export 分别维护安装、工程、排版和导出流程。技能描述只陈述本入口的正向触发范围，不把默认入口的触发词放在原子技能描述中作为反例；显式指定技能时直接交接；不得复制另一入口的参数事实源。

#### Scenario: 显式导出请求
- **WHEN** 用户指定从已有工程导出 PDF
- **THEN** 选择 export，复用已有工程和公共 CLI 契约，不重新创建工程。

#### Scenario: 通用任务及无关请求
- **WHEN** 用户提出多页手册任务或与排版无关的请求
- **THEN** 前者由 use 识别输入和最短技能链，后者不触发 DesignCraft 安装或写入。

#### Scenario: 内容未齐的可编辑文档目标
- **WHEN** 用户希望从尚未提供的大纲或素材制作两页可编辑版式，且没有单独指定工程生命周期操作
- **THEN** 默认由 use 提问澄清，不因“新建”或“可编辑文档”措辞路由到 document 并启动工程创建。

#### Scenario: 新文档创建与现有工程生命周期操作
- **WHEN** 用户要新建文档（包括空白文档），或只要求打开/保存/另存/重开一个既有工程
- **THEN** 新文档目标由 use 接收并澄清；document 仅处理既有工程的单项生命周期操作。

#### Scenario: Codex 默认和显式技能输入
- **WHEN** Codex 构建未指定技能或显式指定原子技能的模型输入
- **THEN** agents/openai.yaml 仅允许 use 隐式调用；原子技能和插件本地 Harness 的 allow_implicit_invocation 为 false，仍可显式加载。包校验拒绝缺失或错误策略；宿主输入验证不代替实际模型路由和原生验收。

### Requirement: SK-02 场景契约与渐进式资料

每项技能 SHALL 描述适用/不适用范围、输入前置、副作用、输出交接、失败恢复和验收；按需提供域内 references 与 examples，至少覆盖成功、既有项目修改和适用的失败恢复。layout SHALL 覆盖样式、串联文本框、图像、溢出与模板数据合并；export SHALL 区分 PDF/IDML/EPUB/图片的检查与损失。

#### Scenario: 领域流程可执行
- **WHEN** Agent 加载 layout 处理多页正文溢出
- **THEN** 资料提供从文档检查到局部修正及逐页复核的流程，示例参数来自已确认目录而非仅展示查询命令。

### Requirement: SK-03 命令归属与原生事实源

技能库 SHALL 将每个纳入支持范围的命令映射到唯一 ownerSkill，分别记录发现、文档、示例、模拟、原生和宿主验证状态。目录 SHALL 绑定 CLI 版本、二进制和目录摘要；文本参数不得伪装成机器 Schema，动态状态由实际原生会话检查。

#### Scenario: 发现新命令
- **WHEN** 固定 CLI 返回此前未维护的命令
- **THEN** 目录可展示该命令，但覆盖记录标为未验证，不宣称具有已验收业务流程。

#### Scenario: 研究源码不同于固定制品
- **WHEN** 研究源码包含固定 CLI 未发现的接口
- **THEN** 不得执行或宣传固定制品支持该接口；保留差异和升级所需证据。

#### Scenario: 研究源码清单保持独立
- **WHEN** 只有研究源码中的命令注册定义，尚未从固定 CLI 发现原生命令目录
- **THEN** 将静态扫描结果单独绑定研究提交和源码文件 SHA-256，并标记 `RESEARCH_SOURCE_ONLY`；`nativeCatalogStatus` 保持 `NOT_RUN`，研究条目不得获得原生命令 owner 或原生验证状态。

#### Scenario: 原生命令目录身份不完整
- **WHEN** 覆盖表尝试将目录状态标为 `DISCOVERED` 或 `VERIFIED`
- **THEN** 校验必须要求 CLI 版本、原生二进制 SHA-256 和实际目录 SHA-256；缺失任一项即拒绝该目录状态。

### Requirement: SK-04 独立安装与路径契约

每项技能 SHALL 携带完整执行资源，从实际加载目录定位，不要求兄弟技能、工作区源码或全局 CLI。跨技能按名称和可用安装来源交接。离线目录仅支持查询/检查；在线调用可能安装依赖，必须沿用实际安装授权，不能把查询请求自动等同于安装授权。

#### Scenario: 独立路径含中文空格
- **WHEN** 单项技能被复制至含中文和空格的隔离目录
- **THEN** 离线 list/describe/check 可运行，原有项目和兄弟技能不存在也不影响资源定位。

#### Scenario: 无离线执行许可
- **WHEN** 用户用显式离线 catalog 发起 run
- **THEN** 执行被拒绝，且未安装运行时、未编辑工程。
