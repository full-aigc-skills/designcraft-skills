# 工程生命周期场景

## 成功示例：既有工程另存副本
- **前置：** 用户提供既有源工程、允许的工作副本目录和输出位置，并授权保存。
- **动作：** 登记源身份，检查固定 CLI 的真实命令目录；仅执行受支持的打开/另存步骤，再以独立会话重开目标。
- **预期状态：** 原件保留，副本身份与回执匹配，重开检查绑定新会话。
- **验收：** 目标路径身份正确，工程可重开，页数和链接素材符合既有约定。

## 拒绝与恢复示例：新文档请求或结果未知
- **前置：** 用户要求从内容、大纲或素材新建文档，或既有工程保存调用返回 UNKNOWN。
- **动作：** 新建文档交给 `designcraft-use` 澄清；UNKNOWN 时只读检查目标、进程状态和原回执，不重放保存。
- **预期状态：** 本技能不创建新文档；未知保存结果继续标记 UNKNOWN，不冒称完成。
- **安全下一步：** 只有既有工程身份与保存授权清楚时继续独立重开核验；否则说明缺少的输入或证据。
