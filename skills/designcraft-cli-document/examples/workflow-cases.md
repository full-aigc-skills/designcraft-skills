# DesignCraft 工程管理场景示例

## 成功示例：保存并重新打开工作副本

- **前置：** 用户提供源工程、目标页面要求和输出位置；源工程保留不变，写入授权仅覆盖新建工作副本。
- **动作：** 登记源输入，复制工作副本，读取当前目录并执行已确认的创建/保存步骤；保存后在新会话重新打开。
- **预期状态：** 原件摘要不变，工作副本和工程清单身份匹配，重开后页数、关键文字与链接素材符合任务要求。
- **验收：** 将工程身份与重开状态分开记录；命令零退出不能代替重新打开。

## 拒绝与恢复示例：保存结果未知

- **前置：** 保存命令超时、中断，或没有可信的机器回执/持久检查点。
- **动作：** 保留原回执、日志和工作副本，只读核对已有进程与可重新打开的工程，不重放保存或重新创建命令。
- **预期状态：** `UNKNOWN` / `RECONCILIATION_REQUIRED`，恢复写入保持禁止。
- **安全下一步：** 通过新会话确认工程状态并补齐检查点；无法证明前置状态时向用户说明具体缺口。
