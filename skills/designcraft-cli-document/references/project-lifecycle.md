# 工程生命周期与验收

本参考解释工程新建、打开、保存和重开的证据边界。它不替代固定 CLI 命令目录，也不假定未验证的工程格式细节。

## 输入与工作副本

- 对必须保留的文件使用 `--input <文件或目录>` 登记；原工程需要修改时先复制到本次任务目录，原生编辑只针对副本。
- 登记拒绝缺失文件、符号链接和特殊条目；目录最多 100000 条目。
- 只存在于命令参数且未登记的路径不受输入摘要检查覆盖。摘要检查不是沙箱或备份。
- 在原生编辑前重新核对登记输入与技能资源。发现漂移时停止并说明受影响路径。

## 保存与重开证据

回执身份应绑定计划、命令目录、输入、运行时与技能资源摘要。保存成功后另开会话打开保存目标，并检查文档页数、关键文本和链接素材。只存在回执、文件大小或零退出码时，重开状态仍是 `NOT_RUN`。

若执行超时，保留 partial stdout/stderr 和 `UNKNOWN`；先只读检查回执和输出文件。存在或缺失输出都不能单独推出原生保存是否完成，更不能据此重放写操作。
