# DesignCraft 导出场景示例

## 成功示例：导出已有工程

- **前置：** 可编辑工程已存在且可重开；用户指定格式、目标目录、页面范围和覆盖边界。
- **动作：** 查询当前 CLI 的导出能力；将结果写入新的输出位置，核对导出警告、格式和逐页预览，并生成产物身份清单。
- **预期状态：** 输出文件格式/字节数/摘要与清单一致，工程仍保留且可编辑；格式损失单独列出。
- **验收：** 工程重开、产物身份和视觉审阅分别记录，不能用导出退出码替代。

## 拒绝与恢复示例：导出警告或结果未知

- **前置：** CLI 报告字体/格式限制，或导出超时且是否已写入未知。
- **动作：** 按任务策略分类警告；未知时先检查已有文件和回执，不覆盖、不盲目重试。
- **预期状态：** 未接受的阻塞警告保持失败；未知结果保持 `UNKNOWN`，已有文件证据保留。
- **安全下一步：** 补充授权的字体/格式选择，或核对已有文件摘要后再决定是否执行一次新的导出。
