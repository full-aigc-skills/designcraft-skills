# DesignCraft 版面操作场景示例

## 成功示例：在授权范围内调整局部版面

- **前置：** 用户指定可编辑工作副本、页面/对象和期望变化；当前 CLI 目录已确认目标命令及所需参数。
- **动作：** 检查输入摘要和对象定位，按单会话计划执行局部调整；保存后重开工程并复核受影响页的文字、图像、溢出和对齐。
- **预期状态：** 原件未变，变更限定在授权范围，受影响页面和对应导出重新验证。
- **验收：** 审阅绑定当前工程及预览摘要；结构检查和视觉判断分开记录。

## 拒绝与恢复示例：对象定位或写入状态不确定

- **前置：** 对象 ID 无法从当前工程确认，或执行返回超时/部分完成。
- **动作：** 不猜测对象，不再发出写命令；保存回执并重新打开工程，只读识别实际对象和已发生的变化。
- **预期状态：** 缺身份时拒绝执行；结果不明时保持 `UNKNOWN`，不自动恢复写入。
- **安全下一步：** 重新确认目标对象和影响页面，再从持久工程提出仅剩余步骤。
