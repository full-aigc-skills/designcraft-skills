# 局部排版审阅

本参考用于在固定 CLI 目录验证后规划局部版面操作。这里的检查项不推断未安装版本支持哪些具体命令或参数。

## 修改前

记录当前工程身份、页码、目标对象、对象属性、素材路径、输出位置和修改范围。每次写入前在当前工程重新发现对象；对象 ID 不应跨会话假定有效。

对文字框检查文字是否串联到后续框，以及溢出是否影响其他页面；对图像框检查链接目标、裁切和实际预览；对样式变更检查同名样式影响的对象范围。若固定 CLI 未报告具体内容，标为未核实，不从退出码补造结论。

## 修改后

只复查目标对象和确定的影响页面，核对文字流、溢出、裁切、链接状态及页面对齐。写入结果 UNKNOWN 时只读查看回执和工程，不自动重放；保存后重开要重新发现对象。

局部检查通过只代表版面操作的结构/内容证据。文件导出、工程可重开和视觉审阅仍需独立验收。
