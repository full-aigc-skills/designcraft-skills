# DesignCraft 安装诊断场景示例

## 成功示例：检查已安装运行时

- **前置：** 用户只要求检查安装；无需更新或安装依赖。
- **动作：** 检查当前固定版本、安装回执和二进制摘要；只读核验，不运行安装器。
- **预期状态：** 版本与锁一致时报告 `READY`；版本/摘要核对属于本机可用性证据，不宣称宿主或创作验收通过。
- **验收：** 检查过程不创建或改写运行时目录；若安装文件缺失，报告具体缺项。

## 拒绝与恢复示例：运行时缺失但没有安装授权

- **前置：** 检查发现运行时不存在，用户没有授权下载或安装。
- **动作：** 不调用 bootstrap 安装器，不升级、不改 PATH；提供已锁版本和授权后可执行的检查步骤。
- **预期状态：** `UNAVAILABLE`，没有安装副作用。
- **安全下一步：** 等待用户授权后单独进行安装，再检查版本、二进制摘要与隔离安装目录。
