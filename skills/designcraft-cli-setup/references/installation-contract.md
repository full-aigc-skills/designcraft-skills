# 固定运行时安装合同

运行时锁定版本为 `designcraft-cli` 0.2.1，仅声明支持的 darwin-arm64 制品。URL 与 archive/binary SHA-256 来自本技能 `scripts/runtime.lock.json`；更新必须同时变更锁和相应验证证据。

## 检查结果

- 目标目录缺失：只读状态为未安装。下载、解压和安装目录属于写入，需要明确授权。
- 目录存在且摘要、版本、安装回执一致：可报告本地安装身份通过。
- 目录存在但校验异常：保留原状态用于诊断，不清理、不覆盖、不自动重装。
- 网络失败、哈希不匹配或平台不支持：返回明确失败，不报告部分安装为成功。

安装成功不推出 CLI 命令、Codex 技能发现、模型路由或出版工作流验收通过；它们是独立门禁。
