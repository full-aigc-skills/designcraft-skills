# DesignCraft CLI 场景示例

## 成功示例：查询真实命令目录

- **前置：** 用户只要求了解可用命令；不需要修改工程。离线目录若被使用，必须标记为离线来源。
- **动作：** 从当前固定 CLI 查询目录，再对用户指定的命令 ID 查询参数；不得根据研究源码补造命令。
- **预期状态：** 返回目录来源、命令 ID 和参数事实。只有当前制品、目录摘要和实际查询证据齐备时，状态才能升为已发现/已验证。
- **验收：** 查询命令没有创建或修改用户工程；文档示例不计作原生运行证据。

## 拒绝与恢复示例：命令不存在或目录离线

- **前置：** 用户请求的命令 ID 不在当前目录，或查询只有离线 fixture。
- **动作：** 拒绝调用未知命令；保留目录来源和具体缺失项，不安装 CLI、不编辑工程、不把 fixture 冒充原生目录。
- **预期状态：** `NOT_VERIFIED` 或 `UNAVAILABLE`，没有写入副作用。
- **安全下一步：** 取得经授权的固定 CLI 目录证据后重新查找；若仍不存在，说明当前制品不支持该命令。
