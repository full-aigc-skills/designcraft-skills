# 从提纲到可编辑工程

- **请求：** 依据已核准提纲、品牌素材和印刷尺寸制作多页手册。
- **前置：** 收集目标受众、页数/尺寸、文本/图像来源、输出路径及允许修改的素材范围。
- **动作：** 先由 document 创建工程，再由 layout 实施已授权对象调整，最后由 export 生成指定格式；保存后重开并逐页检查。
- **成功证据：** 原生工程、导出文件、逐页预览与审阅记录分别绑定当前候选摘要。
- **安全下一步：** 缺少源材料或输出授权时停在澄清阶段，不创建临时替代交付物。
- **状态边界：** 该示例为规划模板，固定 CLI 的实际运行证据为 `NOT_RUN`。
