# DesignCraft 通用排版场景示例

## 成功示例：编排多页交付

- **前置：** 用户给出目标、源素材、页面尺寸/页数、内容规范、输出路径和授权边界。
- **动作：** 识别最短技能链；通过 document 建立可编辑工程，通过 layout 完成已授权的页面操作，再交给 export；保存后重开并逐页检查。
- **预期状态：** 工程、导出文件和页审阅都绑定同一候选身份，各自验收；无关能力不被触发。
- **验收：** 报告完成项、证据、未运行层和下一步，不能把计划或零退出称为最终完成。

## 拒绝与恢复示例：无关请求或结果未知

- **前置：** 用户请求与排版无关，或前一步原生调用返回 UNKNOWN。
- **动作：** 无关请求不安装/启动 DesignCraft；UNKNOWN 时先交给只读 receipt/reconcile 流程，禁止新建第二个写任务。
- **预期状态：** 无关请求不产生副作用；未知结果保持待核对且不自动重放。
- **安全下一步：** 仅在需求匹配且工程、runId 与检查点核实后交接剩余工作，否则说明缺少的证据。
